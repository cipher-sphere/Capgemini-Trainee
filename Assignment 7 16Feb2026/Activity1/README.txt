DATA STRUCTURES LAB - ACTIVITY 1
Topic: Binary Search Tree (BST) and Heap Basics
1.	Objective
To implement Binary Search Tree operations (Insert, Search, Traversal) and understand basic Min-Heap functionality.
2.	Activity Tasks
•	Task 1: Create a Binary Search Tree and insert the following elements: 50, 30, 70, 20, 40, 60, 80.
•	Task 2: Perform Inorder, Preorder, and Postorder traversal.
•	Task 3: Search for element 40 and 100 in the BST.
•	Task 4: Implement a Min-Heap using Java PriorityQueue.
•	Task 5: Insert 10 random numbers into Min-Heap and print them in sorted order.
3.	Expected Learning Outcomes
•	Understand BST structure and properties.
•	Perform different tree traversals.
•	Apply search logic using BST property.
•	Understand Min-Heap ordering property.
•	Analyze time complexity of operations.
4.	Submission Requirements
Students must submit: • Java source code file • Screenshot of program output • Short explanation of each operation (Insert, Search, Traversal) • Time complexity analysis of BST and Heap operations
